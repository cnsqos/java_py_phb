사용자가 보기 편한 화면을 만드는 것에 관심이 많습니다. 시멘틱 태그를 활용해 구조를 명확히 작성하려고 노력하고 있으며, 레이아웃, 텍스트 스타일링, 배경, 그림자 효과 등을 구현할 수 있습니다.

기술 스택 / 사용 가능 기술

HTML
  • 시멘틱 태그를 활용해 의미 있는 구조를 작성 할 수 있다
  • 이미지와 링크, 단락, 인라인 텍스트를 적절히 사용할 수 있다
CSS
  • 테두리,배경,글자스타일,박스그림자를 적용할 수 있다
  • 컨테이너 라는 개념을 이해하고, 최대 너비를 제한하고 가운데 정렬하는 레이아웃 박스를 만들 수 있다
